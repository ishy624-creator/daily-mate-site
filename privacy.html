Privacy policy

Daily Mate Uploader · Last updated 24 November 2026

What the app is

Daily Mate Uploader is a personal tool run by the owner of the YouTube channel Daily Mate. It creates chess puzzle videos and uploads them to that one channel. It has no other users and is not offered to the public.

YouTube API Services

The app uses YouTube API Services to upload videos. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the app accesses

The app asks Google for one permission only: youtube.upload, which lets it upload videos to the signed-in account. It does not read, collect or store any information about viewers, subscribers, commenters or any other person.

What data the app stores

  • A sign-in token for the channel owner's own account, kept on the owner's computer (and, if daily posting is switched on, as an encrypted secret in the owner's private GitHub repository).
  • A list of the YouTube video IDs the app has uploaded and the puzzle used for each, so that no puzzle is posted twice.

Nothing else is stored, and no data is sold, shared with third parties or used for advertising.

Removing access

Access can be withdrawn at any time from the Google account's security settings. Deleting the token file removes the stored sign-in. Requests about this policy can be sent to the contact address below; any stored data will be deleted within 7 days of a request.

Changes

If this policy changes, the date at the top of this page will be updated.
